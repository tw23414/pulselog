# PULSELOG version archive

Each release has its own folder containing the files and notes for that version.

| Version | Folder | Summary |
|---|---|---|
| v1 | [versions/v1](./v1/) | Original wellbeing dashboard, trackers, habits and JSON export |
| v2 | [versions/v2](./v2/) | v1 features plus reflections, backup import, install/offline support and a Windows desktop installer |

## Installer links
If a version has a built installer, its version README includes an **Installer** section at the very bottom with the download instructions.

- [PULSELOG v2.0.0 direct Windows EXE release](https://github.com/tw23414/pulselog/releases/tag/v2.0.0) — download the `.exe` asset directly; no ZIP extraction.

## Important
The repository root remains the live GitHub Pages app and the main development copy. Version folders are snapshots for reference; future releases should get a new folder such as `v3/` with that release's app files, README and changelog. If a future version has an installer, publish it as a direct `.exe` release asset and put its download instructions at the very bottom of that version's README.
