# PULSELOG version archive

Each release has its own folder containing the files and notes for that version.

| Version | Folder | Summary |
|---|---|---|
| v1 | [versions/v1](./v1/) | Original wellbeing dashboard, trackers, habits and JSON export |
| v2 | [versions/v2](./v2/) | v1 features plus reflections, backup import, install/offline support and desktop installer configuration |

## Important
The repository root remains the live GitHub Pages app and the main development copy. Version folders are snapshots for reference; future releases should get a new folder such as `v3/` with that release's app files, README and changelog.
