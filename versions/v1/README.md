# PULSELOG — Version 1

This folder preserves the original PULSELOG v1 release.

## Files
- `index.html` — complete standalone v1 application.
- `README.md` — v1 feature and usage notes.
- `CHANGELOG.md` — v1 release notes.

## Features
- Daily wellbeing dashboard.
- Optional food and calorie logging.
- Water tracking.
- Steps, movement and sleep tracking.
- Mood and energy check-ins.
- Custom daily habits and completion tracking.
- Seven-day habit overview.
- JSON data export.

## Run
Open `index.html` in a modern browser. Data is stored locally in that browser.

## Versioning
This is an archived snapshot. New development should happen in the current root app and be copied into a new version folder for each release.
