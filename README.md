# PULSELOG

A lightweight, mobile-friendly daily wellbeing tracker. PULSELOG helps you notice patterns across habits, food, hydration, movement, sleep, mood and energy — without turning wellbeing into a competition.

## Run it
Open [the live app](https://tw23414.github.io/pulselog/) after enabling GitHub Pages, or open `index.html` in a modern browser. No build tools, account, server, or external dependencies are required.

## Included in v2
- Daily dashboard with date selection and a seven-day habit overview
- Optional food and calorie logging (calories can be left blank)
- Water check-ins, steps, movement and sleep logs
- Custom daily habits with completion tracking
- Mood and energy check-ins
- A separate private reflection for each date
- JSON backup export and backup import
- Install prompt for supported browsers
- Offline app shell after the first successful online visit
- Local browser storage; no account or backend

## Publish with GitHub Pages
1. In this repository, open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.
4. After GitHub finishes deploying, the app will be available at the URL above.

## Install
Open the live site in a supported browser. When the browser offers installation, use the **Install PULSELOG** button or the browser's install option. On iPhone/iPad, use Safari's **Share → Add to Home Screen**.

## Privacy and backups
Entries are saved in this browser using `localStorage`. They are not sent to a server. Export your data regularly. Importing a backup replaces entries for dates included in that backup; other dates remain unchanged. Clearing browser site data will remove locally stored entries. Offline access becomes available after the app has been visited online and its files have been cached.

## Important
PULSELOG is a personal journaling tool, not a medical device or source of medical advice. It does not prescribe calorie targets, weight-loss goals, exercise plans, or medication guidance. Calorie tracking is optional.
